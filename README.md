## Build IPA (ស្វ័យប្រវត្តិ)
GitHub Actions នឹង Build .ipa ឲ្យស្វ័យប្រវត្តិនៅពេល push code ទៅ main branch។
ចូល tab Actions -> Download artifact M12Test-IPA -> បាន M12Test.ipa

## ដំឡើង .ipa
- AltStore / Sideloadly / TestFlight (សម្រាប់ Unsigned IPA)
- ត្រូវការ Khmer voice: Settings > Accessibility > Spoken Content > Voices > Khmer
